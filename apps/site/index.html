One chat box. Real tools.

Remy works in small steps with the tools below until the task is done, it needs you, or it reaches a limit.

It works on your files.

Read, write, edit, move and delete inside one workspace folder you choose. It runs one allowlisted program at a time, such as git, grep or pnpm, and every command asks first.

It uses the web like you do.

Remy has its own browser on your computer. It searches, follows links, uses a site's search box and fills in fields. It never types passwords or card numbers: it shows you the window and you do that part.

It connects to your apps.

Remy uses apps through MCP: GitHub, Notion, Linear and Sentry are on the built-in list, and you can add any other server. A connection's tool asks before it acts, unless it is marked read-only.

Each yes covers one exact action.

An approval is tied to the specific call, used once, and gone. Deleting files, running commands, sending as you and spending money always ask, whatever you allow.

Pages cannot give orders.

Text from web pages, email, connections and command output is marked untrusted. Once a task has seen any, every action that is not a read needs your approval, so an instruction hidden in a page cannot act for you.

You choose how much it asks.

By default it asks. Steady clears a short list of low-risk, reversible work in the workspace; away clears a little more for long runs while you are gone. Neither ever clears spending, sending, deleting or anything after a page it could not trust.

A crash loses nothing.

Every task is an append-only log. If Remy stops, it continues from the log. An action that may already have happened is checked or reported, never repeated blindly.

Questions.

Which models does it use?

Yours. OpenAI, Anthropic, Google Gemini, OpenRouter, Groq, Ollama, or any OpenAI-compatible endpoint such as vLLM or LM Studio. Run remy login once and your key goes in the macOS Keychain or a private file. A typical task costs a fraction of a cent on a small model.

Does my data leave my machine?

Your files and notes stay where they are. What Remy reads to do a task is sent to the model provider you chose, and nothing else is sent anywhere. Secrets are kept out of what the model sees.

What if it gets something wrong?

It stops at limits you set: 30 steps, $1 or 30 minutes by default, then asks to continue. Anything that changes something waits for your yes first. Stop it any time; the log shows exactly what it did.

What can it not do yet?

No voice, desktop or mobile app. No Slack or Google Workspace on the built-in list; you can still add their servers yourself. The command tool is not a full sandbox, so read each command before you approve it. Free and weaker models are less reliable. The web app is built but not released.

Is it open source?

The code is Apache-2.0 on GitHub. The Remy name and logo are not licensed with it.
