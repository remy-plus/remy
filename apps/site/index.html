Real work, done wherever you are.

Remy is one calm assistant for real digital work. Describe a task in plain words; it reads, searches and acts in small steps, and asks before anything that matters.

It lives in your terminal today. Web, desktop, mobile and voice are on the way.

Get Remy Follow along on GitHub

Terminal · available now

$ npm install -g @koryei/remy

Needs Node 22.18 or newer. Then run remy to open the chat. Model setup is below.

What it does today.

In the terminal, Remy works in small steps with these tools until the task is done, it needs you, or it hits a limit.

  • FilesRead, list, write, edit, move and delete inside one workspace folder.
  • WebFetch pages. Search with a Brave, Tavily or SearXNG key. Limit browsing to domains you name.
  • CommandsRun one allowlisted program at a time, such as git, grep, node or pnpm. Every command asks first.
  • MathArithmetic and date math, such as the days between two dates.
  • QuestionsWhen it needs something only you know, it asks. At most three times per task.
  • ModelsAny OpenAI-compatible endpoint: OpenAI, OpenRouter, Ollama, vLLM or Groq.

An example session in the terminal today. Remy fetches a page, then stops to ask before it writes a file.

Nothing happens that you did not approve.

Approvals bind to the exact action

Each yes covers one specific call and is used once. Deleting files, running commands and spending money always ask, whatever you allow.

Untrusted content is marked

Text from web pages and command output is untrusted. Once a task has seen it, every action that is not a read needs your approval, so a hidden instruction in a page cannot act for you.

Crash-safe resume

Every task is an append-only log. After a crash or Ctrl+C, remy resume continues from where it stopped.

No double actions

An action that may already have happened is checked or reported, never blindly repeated. Tasks stop at 30 steps, $1 or 30 minutes.

Pick a model and talk.

  1. Pick a model
    export REMY_PROFILE=openrouter
export OPENROUTER_API_KEY=sk-or-...
export REMY_MODEL=google/gemma-4-26b-a4b-it:free

# or local
# REMY_PROFILE=ollama REMY_MODEL=qwen2.5:7b
  2. Open the chat
    remy

# one task, for scripts
remy run "summarize README.md"

Not installed yet? The commands are under Get Remy, at the top of the page.

Not yet.

  • Only the terminal exists. Web, desktop, mobile and voice are planned and not built.
  • No browser automation: it reads pages but cannot click or fill forms.
  • No real email, calendar or account integrations.
  • Ctrl+C stops the task, but a tool already running finishes its current call.
  • run_command is not a full sandbox. Read each command before you approve it.
  • No memory across chats beyond the current conversation, and no scheduled tasks.
  • Free and weaker models are less reliable than the numbers above.
