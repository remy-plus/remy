# App marks

Most marks here come from [Simple Icons](https://simpleicons.org) (data under CC0-1.0), set to each
brand's own colour. The marks themselves are the trademarks of their owners and are used only to
identify the app a person connects. No endorsement is implied.

`filesystem`, `fetch` and `memory` are drawn for Remy (24 px grid, 1.6 stroke, like the app's own
icons) and are not brands. Older marks (gmail, calendar, drive, notion, slack, octocat, linear,
dropbox, stripe, zoom, figma) were added earlier.

Not bundled, because Simple Icons no longer carries them: Salesforce, Amazon Web Services, Twilio,
OpenAI, Microsoft (Outlook, Teams, OneDrive), monday.com. Those apps show a letter instead.
