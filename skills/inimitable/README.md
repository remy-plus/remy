# inimitable

A global design skill: one run that takes a screen, a page, a terminal UI or a native view from "works" to "looks right on first show". It is built to keep improving as more projects are designed with it.

It lives in this repo so it has history. `~/.claude/skills/inimitable` is a symlink to this folder, so the skill works from any project.

## How it is built

**Nothing goes into the skill without the owner's approval.**

1. An idea is proposed in chat, with its source named.
2. The owner approves it, edits it or rejects it.
3. Approved items are added to `DECISIONS.md`, with the date.
4. `SKILL.md` is written only from `DECISIONS.md`.

There is no `SKILL.md` yet, on purpose. The run is being deepened one step at a time.

| 3 Fix the direction | Not started |
| 4 Branch (fix layer by layer, or build around one bright element) | Not started |
| 5 Build | Not started |
| 6 Gate | Not started |
| 7 Look | Not started |

Also open: house rules, the anti-slop list, rules per surface (web app, landing page, terminal, native), the verification method, scripts, and how lessons are recorded after each project.
