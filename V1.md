## Stage 2: Make it smart

- [x] Sources are checked before finishing (Mercury 3 live: 35 to 39 of 39)
- [~] Remy knows what it can and cannot do (built; not tried on a live model)
- [x] Tests for tool and skill choices (42 cases; Mercury 3 live 114 of 126)
- [~] Role helpers and helpers that act with approval (built; `delegate` not proven live, needs a stronger model)
- [~] Levels of trust and tasks that run for hours (`/trust` ask, steady, away, `remy run --for 3h`, and at away a task carries on while up to 3 cards wait; not tried on a live model)
- [~] Search on a fresh machine with no key and nothing on screen (route picked in order with fallback and a named next step; a fresh Mac gets the hidden browser, which is weak; no keyless route is reliable yet)
- [x] Harder live tasks (14 cases; Mercury 3 at 36 of 42, room to beat)
- [ ] **Gate:** sourced answers on hard research, safety and recovery at 100%, a clear win over Stage 1

## Stage 3: Make it learn

- [~] Meaning-based memory search (local ranking with stemming and a small synonym list, embeddings through your own provider with `REMY_EMBEDDINGS=on`; not tried live)
- [x] Merged and flagged notes, SQLite with no cap (notes in `remy.sqlite`, old file imported and kept, clashes flagged, 25 recall cases)
- [x] Corrections become how-tos (`save_howto` after a correction, followed on the next similar task in replay)
- [~] Proposed prompt changes from failed runs, kept only if evals rise and the owner approves (`remy improve propose|check|apply` built with 18 editable and 18 locked texts; never run against a live model)
- [x] Cached share holds as memory grows (prefix repeats 99.98% at 5,000 notes; notes block at most 221 tokens)
- [~] **Gate:** recall suite at about 25 cases (30 in replay), a repeated task visibly improves (in replay; not shown on a live model)
