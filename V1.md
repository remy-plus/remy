## Stage 3: Make it learn

- [ ] Meaning-based memory search
- [ ] Merged and flagged notes, SQLite with no cap
- [ ] Corrections become how-tos

## Stage 4: Give it reach

- [ ] Local voice in the terminal
- [ ] Browser measured, Lightpanda tested as an optional engine
- [ ] Remy's own computer through a container or terminal-mac
- [ ] Boat as an optional cloud computer, on the user's own key
- [ ] `remy doctor` recommends per machine
- [ ] Schedules and daemon on Linux and Windows
- [ ] Webhooks and a review of what ran overnight
- [ ] **Gate:** each works from a clean install, or the owner drops it on purpose

## Stage 5: Design it

- [ ] Brand refresh, two or three directions, owner picks
- [ ] Design system from `branding/`, with Cline as the reference
- [ ] Every core screen prototyped, light and dark, phone size
- [ ] **Gate:** owner signs off on real screens

## Stage 6: Build the web app

- [ ] Server on the `Runtime` API, with streaming
- [ ] Every Stage 5 screen built, including a quiet mode
- [ ] Push-to-talk
- [ ] Docker image and sign-in for a home server or VM
- [ ] **Gate:** every terminal capability works, from a laptop and from a home server by phone, and killing it mid-task loses nothing

## Stage 7: Prove it

- [ ] Non-technical testers finish real tasks unaided
- [ ] Security review and red-team pass
- [ ] Speed, accessibility and failure paths
- [ ] Clean install on machines we do not own
- [ ] **Gate:** no open blockers, final scores beat Stage 1 by a wide margin
