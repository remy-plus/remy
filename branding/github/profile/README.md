<p align="center"><b>Your assistant, anywhere.</b></p>

<br>

Remy is an AI agent that does real digital work from a single chat box. It researches, writes, sends and books. Before anything that spends money, speaks for you, or can't be undone, it asks first.

- **Reliable.** Tasks are durable. A crash resumes where it stopped, and no action runs twice.
- **Safe by design.** Permissions and approvals are enforced in code, not in prompts.
- **Your model.** Works with the model you choose, open-weight models included.
- **Measured.** Every change is checked against an eval suite before it ships.

<sub>Early days. The core runtime is being built now.</sub>
